# ACT 单任务验证

## 任务

使用一个易夹取物体和一个固定盒子。每轮随机改变物体初始位置，在指定时间内将物体放入盒子并释放。任务文本固定为 `Pick up the block and place it in the bin.`。

## 数据

先录制 2 条轨迹验证数据管线，再逐步采集约 50 条成功示范。保持相机名称、动作单位、帧率与标定一致。主实验用两个互补视角；第三个视角可在单独数据版本中保留。

开发数据按完整轨迹划分。最终实机测试采用提前准备的独立摆放方案，不用测试结果反复选择检查点。

## 验收

- 设备、依赖、数据和检查点版本可追溯。
- 数据能录制、检查与回放。
- AutoDL 能训练模型并启动服务。
- 本地能接收并执行云端动作。
- 完成约 20 次有记录的独立实机试验，保留成功与失败视频。
- 记录抓取、搬运、释放、超时和通信失败；区分模型问题与执行问题。

ACT 阶段用于建立可靠流程，成功率按实际结果报告，不预填数值。进入 SmolVLA 前应能解释最主要的失败原因。

## 文件

`experiment.example.json` 提供录制、回放和数据位置配置。`configs/policies/act.json` 提供训练初值。具体启动方式见 [操作流程](../../docs/workflow.md)。
