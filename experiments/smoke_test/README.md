# 可选 smoke test：ACT 链路检查

本目录用于快速检查采集、云端推理与本地执行链路，不承担主线模型对比。已有可用 ACT 检查点时可直接复用；若 SmolVLA 已能完成采集、训练和执行，则跳过 ACT，无需为进入主线额外训练一个模型。

## 检查范围

- 设备配置正确，两个互补视角可用，遥操作正常。
- 录制 2 条短轨迹，检查元信息并回放。
- 如有兼容检查点，启动云端服务，完成少量受控实机执行。
- 保存数据、配置、检查点版本和日志，定位通信、相机映射及动作单位问题。

检查限时半天至一天；没有检查点时可直接用 SmolVLA 小规模试训练验证后续链路。烟雾测试的少量执行仅说明链路是否工作，不作为模型成功率结论。

## ACT 示例

任务为将一个易夹取物体放入固定盒子，任务文本为 `Pick up the block and place it in the bin.`。`act.example.json` 默认录制 2 条轨迹，供数据管线检查；若决定训练 ACT，需另建数据版本并扩充成功示范，不能把这两条调试数据视为充分训练集。

`configs/policies/act.json` 提供训练初值，`configs/deployment/local.example.json` 提供 ACT 客户端示例。具体命令见 [操作流程](../../docs/workflow.md)。
