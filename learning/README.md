# 学习与实践计划

适用背景：已有 LLM 基础与 ACT 运行经历，使用 SO-101 主从单臂、三个摄像头，云端 GPU 训练与推理，本地负责设备。目标是寒假机器人算法实习，侧重 VLA 与多模态模型。

每周安排 3—4 天，约五分之一时间阅读与追代码，其余用于实现和实验。按阶段验收推进；环境问题占用时间时，减少扩展实验，保留主任务与核心评估。

| 阶段 | 学习重点 | 实践任务 | 验收 |
| --- | --- | --- | --- |
| 第 1 周 | 关节状态、动作单位、标定、坐标系、LeRobot 数据格式 | 接通设备与两个视角，录制并回放试验数据 | 能解释每个输入与动作维度，数据与执行设置一致 |
| 第 2 周 | 行为克隆、ACT、动作序列和误差累积 | 训练 ACT，完成云端服务与本地执行 | 能说明训练数据如何变成实际动作 |
| 第 3 周 | SmolVLA 视觉语言骨干、动作专家、流匹配 | 接入四任务试训练，扩充正式数据 | 能追踪图像、文字和状态的前向计算 |
| 第 4 周 | 数据划分、语言依赖、失败归因 | 完成基础与同场景换指令测试 | 形成首版结果、视频、报告，开始投递 |
| 第 5 周 | 指令增强、参数冻结和微调对照 | 根据开发结果实施一个改进 | 能区分改进与其他变量的影响 |
| 第 6 周 | 统计、复现、推理延迟和实验表达 | 补充复测，整理代码与面试材料 | 能完整讲解问题、实现、证据和限制 |

## 投递准备

- 四任务有自主执行与完整测试记录。
- 有相同场景、不同指令的对照。
- 数据、模型、配置、版本和个人贡献清楚。
- 提供可阅读仓库、结果表与演示视频。
- 能解释主要失败与下一步验证方案。

先完成 ACT 工作流；达到投递条件后边投递边补实验。成功率按实际试验报告，不以论文或竞赛奖牌作为启动投递的前提。

资料见 [阅读清单](resources.md)，每周记录使用 [学习记录模板](notes-template.md)。
